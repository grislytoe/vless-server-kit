# VPN на Ubuntu 22.04 одной командой

> **1.1-dev, отдельная тестовая ветка.** Основной выпуск 1.0 находится в `main` и снимке `codex/v1.0`. Порядок обновления без повторного ввода IP и контроль сохранения данных описаны в [CHANGELOG-1.1-RU.md](CHANGELOG-1.1-RU.md). Команды ниже с `/main/` запускают основной выпуск 1.0; для испытания 1.1 используйте только команду из changelog. В релиз 1.1 не включена.

Xray **VLESS + XHTTP + REALITY** для HAPP и веб-панель: создание, просмотр, копирование, QR, деактивация и удаление ключей. Вход в панель по логину и паролю, выбранным при установке.

## Требования

- Чистый выделенный VPS **Ubuntu 22.04** с systemd, архитектура x86_64 или ARM64.
- Root или пользователь с sudo. Рекомендуется от 1 ГиБ RAM и 2 ГиБ свободного диска; 2 ГиБ RAM дают больший запас.
- **Два разных публичных IPv4**, назначенных интерфейсу VPS и маршрутизируемых хостером.
- Зарегистрированный домен или поддомен с прямой **DNS A на основной (первый) публичный IPv4 сервера**, без CDN-проксирования и без AAAA.
- Открытые входящие **TCP 80 и 443**, сохранённый доступ SSH; исходящий HTTPS и UDP DNS.

Второй адрес нужно заранее заказать и назначить у хостера, DNS — настроить у провайдера домена. На сервере с чужими Nginx/Xray/другой VPN-панелью скрипт остановится для проверки конфликтов.

## Домен и порядок IP-адресов

**До запуска установки направьте выбранный домен на основной публичный IPv4 сервера.** В DNS-зоне создайте A-запись: для самого домена обычно используется имя `@`, для поддомена `vpn.example.com` — `vpn`. Значение записи — основной публичный IPv4 VPS, обычно тот же адрес, по которому вы подключаетесь по SSH. Дождитесь применения DNS перед запуском скрипта.

Среди A-записей выбранного имени должен быть только этот основной адрес. Удалите AAAA для выбранного имени и отключите CDN-проксирование, если оно включено. Второй публичный IPv4 используется для выхода VPN в интернет; в A-запись домена панели/VPN его добавлять не нужно.

**При вводе IP сначала указывайте основной адрес сервера, затем второй, дополнительный.** Порядок строк в списке адресов интерфейса не определяет их назначение: основной адрес уточняйте в панели хостера.

## Полная команда

Подключитесь по SSH и выполните одну строку. Она установит curl, если его ещё нет, и запустит интерактивную установку:

```bash
sudo bash -c 'set -euo pipefail; apt-get update; apt-get install -y ca-certificates curl; curl -fsSL https://raw.githubusercontent.com/grislytoe/vless-server-kit/main/start.sh | bash'
```

Если вошли как **root** и `sudo` отсутствует:

```bash
bash -c 'set -euo pipefail; apt-get update; apt-get install -y ca-certificates curl; curl -fsSL https://raw.githubusercontent.com/grislytoe/vless-server-kit/main/start.sh | bash'
```

Параметры в команду подставлять не нужно. Скрипт покажет IPv4 интерфейсов и запросит данные в таком порядке:

1. `Domain` — подготовленный домен или поддомен, без `https://` и пути.
2. `Incoming public IPv4` — **основной (первый) публичный IPv4 сервера**, на который уже указывает A-запись домена. Принимает подключения на TCP 443.
3. `Second public IPv4` — **второй, дополнительный публичный IPv4** того же сервера. Используется для исходящего VPN-трафика.
4. Логин панели, затем пароль и повтор пароля.

Пароль вводится скрыто. Весь ввод выполняется в SSH-терминале; при запуске удалённой командой используйте `ssh -t`.

После проверок устанавливаются VPN, Nginx, сертификат и панель. В конце выводится **HTTPS-адрес панели**. Войдите и скопируйте ссылку или скачайте QR нужного ключа для импорта в HAPP.

Запускатель скачивает закреплённую проверенную ревизию с SHA256; архив Xray также закреплён и проверяется. При повторном запуске сохраняются существующие клиенты, ключи и пароль панели. Изменение ключей перезапускает Xray: остальные устройства могут кратко переподключиться.

Подробности, резервные копии и восстановление: [README-RU.md](README-RU.md). Выбор протокола и ограничения маскировки: [PROTOCOL-RU.md](PROTOCOL-RU.md). [Отчёт проверки безопасности](SECURITY-RU.md). Проверки: [GitHub Actions](https://github.com/grislytoe/vless-server-kit/actions).

Нераспознаваемость и максимальная скорость в любой сети не гарантируются. После установки отдельно проверьте HAPP со своего устройства. В репозитории нет действующих паролей, приватных ключей или клиентских ссылок.
